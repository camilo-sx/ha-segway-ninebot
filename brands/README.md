# Iconos para home-assistant/brands

Ilustración **genérica** de un patinete eléctrico (no es el logotipo de Segway;
la marca es de su titular). Para que Home Assistant muestre el icono del
dominio `segway_ninebot`, hay que abrir un PR a
[home-assistant/brands](https://github.com/home-assistant/brands) colocando:

```
custom_integrations/segway_ninebot/icon.png      (256x256)
custom_integrations/segway_ninebot/icon@2x.png   (512x512)
custom_integrations/segway_ninebot/logo.png      (256x256)
custom_integrations/segway_ninebot/logo@2x.png   (512x512)
```

Los PNG están aquí ya con esas dimensiones. `icon.svg` es la fuente editable.
